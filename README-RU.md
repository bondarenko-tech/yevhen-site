# Bondarenko Empfehlungen — SEO-пакет без искусственного noindex (31.10.2026)

Это обновление предыдущего пакета. Сайт — редакционный ресурс с рекомендациями и партнёрскими ссылками Amazon, НЕ магазин. Разметка Product/Offer/MerchantListing не добавлялась.

## Главное изменение
- Страницы бренда с ОДНИМ товаром теперь имеют `index, follow` и включаются в sitemap.
- Страницы «бренд + категория» с ОДНИМ товаром также получают `index, follow` и включаются в sitemap.
- Пустые страницы брендов/категорий (0 товаров) остаются `noindex, follow` и не добавляются в sitemap.
- Количество товаров само по себе не гарантирует индексацию Google: содержимое страниц нужно оценивать отдельно.

## Файлы в пакете
1. `src/content.config.ts` — регистрация существующей коллекции ratgeber.
2. `src/pages/sitemap.xml.ts` — адреса по маршрутам Astro и порог для брендов 1 вместо 2.
3. `src/pages/image-sitemap.xml.ts` — снято ограничение на длину текста.
4. `src/pages/marken/[brand]/index.astro` — индексирование непустых брендовых страниц.
5. `src/pages/marken/[brand]/[kategorie].astro` — индексирование непустых брендовых категорий.

## Установка — только после проверки
Это лишь изменённые файлы, а не полный репозиторий. Сначала сделай резервную копию/ветку, замени файлы в локальном проекте и запусти в VS Code из корня проекта `npm run build`. При ошибке ничего не публикуй, пришли вывод терминала.

**Не проверено:** полноценная сборка Astro и реальные ответы сервера. Не устранены все 404, перенаправления и вопросы качества страниц. Не следует запускать в GSC проверку исправления до успешной публикации.
