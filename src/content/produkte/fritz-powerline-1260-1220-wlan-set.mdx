## ⚡ Wie funktioniert Powerline?

👉 statt WLAN nutzt das System:

➡️ **Stromleitung als Datenleitung**

Router → Steckdose → Adapter → WLAN im Zielraum  

👉 Vorteil:

- Signal geht durch Wände  
- stabiler als Repeater  
- keine Kabelverlegung
