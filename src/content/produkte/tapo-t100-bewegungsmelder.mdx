## Kurzfazit

Der **Tapo T100** ist ein kompakter Bewegungsmelder für das Tapo Smart Home. Er erkennt Bewegungen in einer Entfernung von **bis zu 7 Metern** bei einem **Sichtfeld von 120°**.

Seine Stärke liegt nicht nur bei Sicherheitsfunktionen. Der Sensor kann auch als Auslöser für Automationen dienen: Eine Lampe kann beispielsweise automatisch eingeschaltet werden, sobald jemand einen Flur betritt.

Auch kompatible Tapo-Steckdosen, Lampen und LED-Strips können in entsprechende Automationen eingebunden werden.

Wichtig vor dem Kauf: **Der Tapo T100 benötigt einen kompatiblen Tapo Hub.**

## Bewegung erkennen statt Schalter drücken

Ein typisches Einsatzgebiet des T100 ist die automatische Beleuchtung.

Der Sensor erkennt, wenn jemand einen Raum oder Flur betritt. Anschließend kann über eine zuvor eingerichtete Automation beispielsweise eine kompatible Tapo-Lampe eingeschaltet werden.

So sind einfache Abläufe möglich wie:

**T100 → Bewegung erkannt → Licht an**

Das kann besonders praktisch sein in:

- Fluren
- Treppenbereichen
- Eingangsbereichen
- Schlafzimmern
- Abstellräumen
- anderen Bereichen, in denen Licht automatisch reagieren soll

## Automationen mit Tapo-Geräten

Der T100 lässt sich mit kompatiblen Geräten aus dem Tapo-System für Smart Actions verwenden.

Dazu können beispielsweise gehören:

- Tapo-Lampen
- Tapo-LED-Strips
- Tapo-Steckdosen

Damit kann eine erkannte Bewegung zum Auslöser einer Automation werden.

Welche Kombinationen und Funktionen verfügbar sind, hängt von den jeweils verwendeten Tapo-Geräten und deren Kompatibilität ab.

## Auch für Sicherheit interessant

Der Tapo T100 kann nicht nur Komfort-Automationen auslösen.

Wird Bewegung erkannt, kann das Tapo-System auch eine entsprechende Benachrichtigung an das Smartphone senden.

Damit lässt sich der Sensor beispielsweise zur Überwachung eines bestimmten Bereichs verwenden, wenn niemand zu Hause sein sollte.

In Verbindung mit einem kompatiblen Tapo Hub können außerdem entsprechende Alarm-Aktionen eingerichtet werden.

Der T100 ersetzt damit zwar keine vollständige professionelle Alarmanlage, kann aber eine praktische Ergänzung eines Tapo-Sicherheitssystems sein.

## Bis zu 7 Meter Erkennungsreichweite

Der Tapo T100 erkennt Bewegungen laut Hersteller in einer Entfernung von **bis zu 7 Metern**.

Das Sichtfeld beträgt **120°**.

Damit kann ein relativ großer Bereich vor dem Sensor überwacht werden.

Die tatsächliche Erkennung kann jedoch von Montageposition, Ausrichtung und Umgebung abhängen.

## Drei Empfindlichkeitsstufen

Die Empfindlichkeit der Bewegungserkennung kann in **drei Stufen** angepasst werden.

Das ist praktisch, wenn der Sensor nicht auf jede Bewegung im maximal möglichen Bereich reagieren soll.

Durch eine passende Einstellung kann die Erkennungszone besser an den jeweiligen Raum angepasst werden.

## Flexibler Sensorwinkel

Der T100 wird auf einer beweglichen Halterung montiert.

Dadurch lässt sich der Sensor in die gewünschte Richtung drehen und ausrichten.

Das ist beispielsweise hilfreich, wenn nur ein bestimmter Bereich eines Raumes überwacht werden soll.

Auch unerwünschte Auslösungen durch Bewegungen außerhalb der gewünschten Zone können dadurch reduziert werden.

## Einfache Montage

Für die Montage bietet der T100 zwei praktische Möglichkeiten.

Der Sensor kann über:

- die magnetische Befestigung
- das mitgelieferte 3M-Klebepad

angebracht werden.

Dadurch ist für viele Montageorte kein Bohren erforderlich.

Die magnetische Befestigung erleichtert außerdem das spätere Ausrichten oder Abnehmen des Sensors.

## Batteriebetrieb mit CR2450

Der Tapo T100 benötigt keine permanente Stromversorgung.

Er wird mit einer **CR2450-Knopfzelle** betrieben.

Laut Hersteller kann die Batterielaufzeit unter den angegebenen Testbedingungen **bis zu zwei Jahre** betragen.

Diese Angabe basiert auf Herstellertests mit ungefähr 50 Auslösungen pro Tag beziehungsweise insgesamt rund 25.000 Auslösungen.

Die tatsächliche Batterielaufzeit kann je nach Nutzung, Anzahl der Auslösungen und Umgebungsbedingungen abweichen.

Ist die Batterie leer, kann sie durch eine neue CR2450 ersetzt werden.

## Tapo Hub ist erforderlich

Das ist der wichtigste Punkt vor dem Kauf:

**Der Tapo T100 funktioniert nicht als eigenständiger WLAN-Bewegungsmelder.**

Für den Betrieb wird ein **kompatibler Tapo Hub** benötigt.

Wer noch keinen passenden Hub besitzt, sollte dessen zusätzliche Kosten deshalb bei der Kaufentscheidung berücksichtigen.

Wer bereits ein Tapo-System mit kompatiblem Hub verwendet, kann den T100 dagegen relativ einfach in dieses System integrieren.

## T100 und Tapo H100

Für ein einfaches System aus Sensoren und Smart-Home-Automationen kann der **Tapo H100** eine passende Zentrale sein.

Der Hub verbindet kompatible Tapo-Sensoren mit dem Tapo-System und ermöglicht entsprechende Automationen.

Wer hauptsächlich Sensoren, Taster und einfache Smart-Home-Aktionen verwenden möchte, benötigt dafür nicht zwingend eine große HomeBase.

## T100 in einem größeren Tapo-System

Der T100 kann auch Bestandteil eines umfangreicheren Tapo-Systems sein.

Wer neben Sensoren beispielsweise mehrere Kameras und lokale Videospeicherung einsetzen möchte, kann eine leistungsfähigere Zentrale interessant finden.

Die genaue Kompatibilität des T100 mit dem jeweils verwendeten Hub sollte vor dem Kauf anhand der aktuellen Angaben von TP-Link geprüft werden.

- ein vollständig eigenständiger WLAN-Bewegungsmelder gesucht wird

Ja. In Verbindung mit einem kompatiblen Tapo Hub und kompatiblen Tapo-Geräten können entsprechende Smart-Home-Automationen eingerichtet werden.
