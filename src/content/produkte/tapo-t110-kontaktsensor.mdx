## Kurzfazit

Der **Tapo T110** ist ein kompakter Kontaktsensor für Türen und Fenster. Er erkennt, ob eine Tür oder ein Fenster geöffnet beziehungsweise geschlossen wird.

Das ist sowohl für die Sicherheit als auch für einfache Smart-Home-Automationen interessant.

Wird beispielsweise eine Tür geöffnet, kann der T110 eine entsprechende Aktion im Tapo-System auslösen. So lässt sich etwa eine kompatible Lampe automatisch einschalten.

Auch Smartphone-Benachrichtigungen sind möglich, wenn eine überwachte Tür oder ein Fenster geöffnet wird.

Wichtig vor dem Kauf:

**Der Tapo T110 benötigt einen kompatiblen Tapo Hub.**

## Türen und Fenster überwachen

Der Tapo T110 besteht aus zwei Teilen:

- dem eigentlichen Sensor
- einem Magneten

Der größere Sensor wird normalerweise am festen Rahmen und der kleinere Magnet am beweglichen Tür- oder Fensterflügel angebracht.

Sind Tür oder Fenster geschlossen, befinden sich beide Teile dicht nebeneinander.

Beim Öffnen vergrößert sich der Abstand zwischen Sensor und Magnet. Dadurch erkennt das Tapo-System die Zustandsänderung.

So lässt sich beispielsweise überprüfen, ob ein Fenster geöffnet wurde.

## Sofortige Benachrichtigungen

Eine der praktischsten Funktionen des T110 sind Smartphone-Benachrichtigungen.

Wird eine überwachte Tür oder ein Fenster unerwartet geöffnet, kann über das Tapo-System eine entsprechende Benachrichtigung auf dem Smartphone erscheinen.

Das kann beispielsweise interessant sein für:

- Haustüren
- Balkontüren
- Terrassentüren
- Fenster
- Abstellräume
- andere Bereiche, deren Öffnungszustand überwacht werden soll

Welche Benachrichtigungen und Aktionen verfügbar sind, hängt von der jeweiligen Konfiguration des Tapo-Systems ab.

## Mehr als nur ein Sicherheitssensor

Der T110 kann nicht nur melden, dass eine Tür oder ein Fenster geöffnet wurde.

Der erkannte Zustand kann auch als Auslöser für Smart-Home-Automationen verwendet werden.

Ein einfaches Beispiel:

**Tür geöffnet → Licht an**

Damit kann beim Öffnen einer Tür automatisch eine kompatible Tapo-Lampe eingeschaltet werden.

## Automatische Lichtsteuerung

In Verbindung mit einem kompatiblen Tapo Hub und kompatiblen Tapo-Geräten lassen sich verschiedene Smart Actions einrichten.

Dazu können beispielsweise gehören:

- Tapo-Lampen
- Tapo-LED-Strips
- Tapo-Steckdosen

Dadurch sind einfache Abläufe möglich wie:

**T110 → Tür geöffnet → Licht einschalten**

Das kann beispielsweise in einem Flur, Eingangsbereich, Abstellraum oder anderen Bereichen praktisch sein.

## Auch für Sicherheit interessant

Der T110 kann als Bestandteil eines Tapo-Sicherheitssystems eingesetzt werden.

Wird eine Tür oder ein Fenster geöffnet, kann das System darauf reagieren.

Neben Smartphone-Benachrichtigungen kann ein kompatibler Tapo Hub beispielsweise entsprechende Alarmaktionen auslösen.

Der T110 ersetzt damit keine professionelle Alarmanlage, kann aber eine praktische Ergänzung eines bestehenden Tapo-Smart-Home-Systems sein.

## Über 1 Jahr Batterielaufzeit

Der Tapo T110 benötigt keine permanente Stromversorgung.

Er wird mit einer **CR2032-Knopfzelle** betrieben.

Laut Hersteller beträgt die Batterielaufzeit unter den angegebenen Testbedingungen **mehr als ein Jahr**.

Diese Herstellerangabe basiert auf Tests mit etwa **60 Auslösungen pro Tag beziehungsweise insgesamt 22.000 Auslösungen**.

Die tatsächliche Batterielaufzeit kann je nach Nutzung, Anzahl der Auslösungen und Umgebungsbedingungen abweichen.

Bei niedrigem Batteriestand kann die Tapo-App entsprechend informieren.

Die CR2032-Batterie ist im Lieferumfang enthalten.

## Einfache Montage

Für die Montage sind keine komplizierten Arbeiten erforderlich.

Sensor und Magnet werden mit den vorgesehenen Klebeflächen an Tür beziehungsweise Fenster angebracht.

Dabei ist die richtige Position wichtig.

Der **größere Hauptsensor gehört auf den festen Rahmen**, während der **kleinere Magnet am beweglichen Tür- oder Fensterflügel** angebracht wird.

Im geschlossenen Zustand müssen beide Teile nahe genug nebeneinander liegen.

Laut Hersteller kann der Abstand zwischen Sensor und Magnet **bis zu 15 mm** betragen.

Vor dem endgültigen Festkleben sollte deshalb geprüft werden, ob der Sensor beim Öffnen und Schließen zuverlässig reagiert.

## Tapo Hub ist erforderlich

Das ist der wichtigste Punkt vor dem Kauf:

**Der Tapo T110 funktioniert nicht als eigenständiger WLAN-Sensor.**

Für den Betrieb wird ein **kompatibler Tapo Hub** benötigt.

Wer noch keinen passenden Hub besitzt, sollte dessen zusätzliche Kosten deshalb bei der Kaufentscheidung berücksichtigen.

Wer bereits ein kompatibles Tapo-System verwendet, kann den T110 dagegen relativ einfach in dieses System integrieren.

Beispielsweise können Kontaktsensoren, Bewegungsmelder, Smart Buttons, Lampen oder Steckdosen miteinander kombiniert werden.

## Häufige Fragen

### Was erkennt der Tapo T110?

Der T110 erkennt, ob eine Tür, ein Fenster oder eine andere entsprechend ausgestattete Öffnung geöffnet beziehungsweise geschlossen wird.

### Kann ich eine Benachrichtigung erhalten, wenn eine Tür geöffnet wird?

Ja. Über das Tapo-System können entsprechende Smartphone-Benachrichtigungen eingerichtet werden.

### Kann der T110 automatisch Licht einschalten?

Ja. In Verbindung mit einem kompatiblen Tapo Hub und kompatiblen Tapo-Geräten können entsprechende Smart-Home-Automationen eingerichtet werden.

Beispielsweise kann das Öffnen einer Tür das Einschalten einer Tapo-Lampe auslösen.

### Benötigt der Tapo T110 einen Hub?

Ja.

**Ein kompatibler Tapo Hub ist erforderlich.**

### Funktioniert der T110 direkt über WLAN?

Der T110 ist kein eigenständiger WLAN-Kontaktsensor. Für die Einbindung in das Tapo-System benötigt er einen kompatiblen Tapo Hub.

### Welche Batterie verwendet der T110?

Der Sensor verwendet eine **CR2032-Knopfzelle**.

Eine Batterie ist im Lieferumfang enthalten.

### Wie lange hält die Batterie?

TP-Link gibt unter seinen Testbedingungen eine Batterielaufzeit von **mehr als einem Jahr** an.

Die tatsächliche Laufzeit hängt unter anderem von der Anzahl der Auslösungen und den Einsatzbedingungen ab.

### Wie groß darf der Abstand zwischen Sensor und Magnet sein?

Laut Hersteller ist ein Abstand von **bis zu 15 mm** möglich.

Für eine zuverlässige Funktion sollte die Montage anschließend getestet werden.

### Wo wird der größere Sensor montiert?

Der größere Hauptsensor wird normalerweise auf dem **festen Tür- oder Fensterrahmen** montiert.

Der kleinere Magnet gehört auf den **beweglichen Tür- oder Fensterflügel**.
