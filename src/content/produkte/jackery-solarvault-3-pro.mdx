## Kurzfazit

Der **Jackery SolarVault 3 Pro** ist ein erweiterbarer Solarspeicher für Haushalte, die einen größeren Teil ihres selbst erzeugten Solarstroms später nutzen möchten.

Die Basisversion bietet **2,52 kWh Speicherkapazität**. Laut Jackery kann das System auf bis zu **15,12 kWh** erweitert werden.

Zu den wichtigsten Eigenschaften gehören:

- 2,52 kWh Speicherkapazität
- bis zu 4000 W PV-Eingangsleistung
- 4 MPPT
- bis zu 1200 W Netzleistung
- Notstromfunktion
- erweiterbarer Speicher
- Steuerung über die Jackery App
- WLAN, Bluetooth und Ethernet

Damit ist der SolarVault 3 Pro nicht nur für ein klassisches Balkonkraftwerk interessant. Er kann auch für Haushalte interessant sein, die bereits eine Solaranlage besitzen oder ihr Energiesystem später erweitern möchten.

## Was macht der Jackery SolarVault 3 Pro?

Solarstrom wird häufig genau dann produziert, wenn im Haushalt relativ wenig Strom benötigt wird.

Ein Batteriespeicher kann einen Teil dieses überschüssigen Stroms speichern.

Die gespeicherte Energie steht anschließend zu einem späteren Zeitpunkt zur Verfügung – beispielsweise am Abend, wenn die Solarmodule kaum noch Leistung liefern.

Genau dafür ist der **SolarVault 3 Pro** vorgesehen.

## 2,52 kWh Speicher

Die Basisversion verfügt über eine Speicherkapazität von **2,52 kWh**.

Das ist bereits deutlich mehr als bei vielen kleinen Speichern für Balkonkraftwerke.

Wie viel davon im Alltag sinnvoll genutzt werden kann, hängt allerdings vom eigenen Stromverbrauch und von der Solarleistung ab.

Ein größerer Speicher bedeutet nicht automatisch eine größere Ersparnis.

Entscheidend ist, ob genügend Solarstrom zum Laden vorhanden ist und die gespeicherte Energie anschließend auch verbraucht wird.

## Speicher später erweitern

Interessant ist die Möglichkeit, das System später zu erweitern.

Jackery gibt für den SolarVault 3 Pro eine erweiterbare Kapazität von **2,52 bis 15,12 kWh** an.

Dadurch muss nicht unbedingt von Anfang an die maximale Speicherkapazität gekauft werden.

Das kann beispielsweise interessant sein, wenn später weitere Solarmodule hinzukommen oder der Stromverbrauch im Haushalt steigt.

Vor einer Erweiterung sollte geprüft werden, welche zusätzlichen Batteriemodule mit dem konkreten System kompatibel sind.

## Bis zu 4000 W Solar-Eingang

Jackery gibt eine maximale PV-Eingangsleistung von **bis zu 4000 W** an.

Damit kann der Speicher mit deutlich mehr Solarleistung arbeiten als typische kleine Balkonkraftwerk-Speicher.

Vier **MPPT** helfen dabei, unterschiedliche Solarstränge beziehungsweise Modulgruppen zu verwalten.

Das kann besonders praktisch sein, wenn Solarmodule unterschiedlich ausgerichtet sind.

Zum Beispiel:

- Module auf dem Balkon
- Module auf einem Flachdach
- unterschiedliche Ausrichtung nach Ost und West
- unterschiedliche Sonneneinstrahlung im Tagesverlauf

Die tatsächlich mögliche Konfiguration hängt jedoch von den elektrischen Daten der verwendeten Solarmodule und den zulässigen Eingangsbereichen des SolarVault ab.

## 1200 W Netzleistung

Der SolarVault 3 Pro kann laut Anbieter bis zu **1200 W Netzleistung** bereitstellen.

Jackery nennt außerdem eine maximale Bypass-Leistung von **2300 W**.

Welche Leistung in Deutschland in der jeweiligen Installation tatsächlich genutzt beziehungsweise ins Hausnetz eingespeist werden darf, hängt von der konkreten Installation und den geltenden Anforderungen ab.

Deshalb sollte man die Leistungsangaben des Gerätes nicht automatisch mit der zulässigen Einspeiseleistung eines Balkonkraftwerks gleichsetzen.

## Notstromversorgung

Der SolarVault 3 Pro bietet laut Jackery eine **Notstromleistung von bis zu 1200 W**.

Damit können bei einem Stromausfall ausgewählte wichtige Geräte versorgt werden.

Welche Geräte tatsächlich betrieben werden können, hängt von deren Leistungsaufnahme und insbesondere von möglichen hohen Einschaltströmen ab.

Ein Batteriespeicher ersetzt deshalb nicht automatisch eine vollständige Notstromversorgung für das gesamte Haus.

## Drei Möglichkeiten zur Einbindung

Jackery beschreibt mehrere Möglichkeiten, den SolarVault 3 Pro in ein Energiesystem einzubinden.

## Ethernet zusätzlich zu WLAN

Ein interessantes Detail ist der **Ethernet-Anschluss**.

Viele Energiesysteme setzen ausschließlich auf WLAN.

Eine kabelgebundene Netzwerkverbindung kann sinnvoll sein, wenn der Speicher an einem Standort steht, an dem das WLAN schwach oder instabil ist.

Zusätzlich unterstützt das System laut Anbieter WLAN und Bluetooth.

Bluetooth kann unter anderem für eine lokale Steuerung ohne Internetverbindung interessant sein.

## Energiemanagement mit Smart Meter

Für eine automatische Anpassung an den tatsächlichen Stromverbrauch muss das Energiesystem wissen, wie viel Energie der Haushalt gerade benötigt.

Dafür können entsprechende Smart-Meter-Lösungen eingesetzt werden.

Das Prinzip ist einfach:

**Hausverbrauch → Messung → Energiemanagement → Speicher**

Dadurch kann die Leistungsabgabe besser an den aktuellen Verbrauch angepasst werden.

Vor dem Kauf sollte geprüft werden, welcher Jackery Smart Meter beziehungsweise welche Messlösung für die gewünschte Installation erforderlich und kompatibel ist.
