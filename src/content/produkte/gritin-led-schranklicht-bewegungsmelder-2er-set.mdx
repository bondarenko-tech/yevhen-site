## Kurzfazit

Das **Gritin LED-Schranklicht** ist eine einfache Lösung für Stellen, an denen Licht gebraucht wird, aber kein Stromkabel verlegt werden soll.

Das Set enthält **zwei LED-Leuchten**. Sie kombinieren:

- Bewegungsmelder
- wiederaufladbaren Akku
- USB-C-Laden
- magnetische Befestigung
- drei Lichtfarben mit **3000 K, 4500 K und 6000 K**

Damit eignet sich das Set beispielsweise für die Arbeitsfläche in der Küche, Schränke oder einen dunklen Flur.

## Licht ohne festes Stromkabel

Der wichtigste Vorteil dieser Leuchten ist die flexible Platzierung.

Da die Gritin-Leuchten mit einem Akku betrieben werden, muss am Montageort nicht direkt eine Steckdose vorhanden sein.

Das ist praktisch unter Küchenschränken oder in Bereichen, in denen ein zusätzliches Kabel stören würde.

Der Akku muss allerdings regelmäßig geladen werden. Wie häufig das nötig ist, hängt von der Nutzung ab.

## Bewegungsmelder für automatisches Licht

Der integrierte **Bewegungsmelder** kann das Licht automatisch aktivieren, wenn sich jemand nähert.

Das ist besonders praktisch, wenn gerade keine Hand frei ist oder nur kurz Licht benötigt wird.

Typische Einsatzorte sind:

- unter Küchenschränken
- in Schränken
- im Flur
- in dunklen Nischen
- an Arbeitsflächen

So muss nicht jedes Mal manuell nach einem Lichtschalter gesucht werden.

## Drei Lichtfarben

Die Leuchten bieten drei Farbtemperaturen:

- **3000 K** – warmes Licht
- **4500 K** – neutraleres Licht
- **6000 K** – kühleres, weißes Licht

Dadurch lässt sich die Beleuchtung besser an den jeweiligen Einsatzort anpassen.

Für eine gemütlichere Umgebung kann 3000 K angenehm sein. Für eine Arbeitsfläche können 4500 K oder 6000 K sinnvoller wirken.

## Magnetische Befestigung

Die Leuchten werden **magnetisch befestigt**.

Das hat einen praktischen Vorteil: Zum Laden können sie leicht von der Halterung genommen und anschließend wieder eingesetzt werden.

Gerade bei einer Akku-Leuchte ist das komfortabler als eine dauerhaft verschraubte Montage.

Vor der Montage sollte die vorgesehene Oberfläche sauber, trocken und für die verwendete Befestigung geeignet sein.

## Laden per USB-C

Zum Aufladen wird **USB-C** verwendet.

Dadurch ist kein fest angeschlossenes Stromkabel nötig. Die Leuchte kann zum Laden von der magnetischen Halterung genommen werden.

Ein passendes Ladegerät beziehungsweise eine geeignete USB-Stromquelle sollte vorhanden sein.

## Zwei Leuchten im Set

Im Angebot sind **zwei Leuchten** enthalten.

Damit können beispielsweise zwei Bereiche gleichzeitig beleuchtet werden:

- zwei Küchenschränke
- zwei Regalböden
- Küche und Flur
- zwei verschiedene Schränke

Das 2er-Set ist besonders praktisch, wenn mehrere dunkle Stellen mit demselben Lichtsystem ausgestattet werden sollen.

## Für wen eignet sich das Gritin Schranklicht?

Das Set ist interessant für Nutzer, die unkompliziert zusätzliches Licht benötigen und dabei möglichst auf neue Kabel verzichten möchten.

Besonders sinnvoll kann es sein für:

- Küchen ohne ausreichende Unterbauleuchten
- dunkle Schränke
- Regale
- Flure
- Abstellbereiche
- Mietwohnungen, wenn eine einfache nachrüstbare Lösung gesucht wird

## Für wen eher nicht?

Weniger passend ist eine Akku-Leuchte, wenn dauerhaft über viele Stunden sehr helles Licht benötigt wird.

In diesem Fall kann eine fest angeschlossene Unterbauleuchte sinnvoller sein.

Auch wenn regelmäßiges Aufladen vermieden werden soll, ist eine kabelgebundene Lösung möglicherweise praktischer.
