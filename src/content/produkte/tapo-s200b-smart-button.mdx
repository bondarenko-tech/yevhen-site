## Kurzfazit

Der **Tapo S200B** ist eine kleine physische Fernbedienung für kompatible Geräte im Tapo Smart Home.

Statt für jede einfache Aktion das Smartphone herauszuholen und die Tapo-App zu öffnen, lassen sich häufig verwendete Funktionen direkt über den Button auslösen.

Besonders praktisch sind die verschiedenen Bedienmöglichkeiten: **Einzeltippen, Doppeltippen und Drehen**. Damit können bis zu **vier unterschiedliche Aktionen** eingerichtet werden.

Wichtig vor dem Kauf: Der **Tapo S200B benötigt einen kompatiblen Tapo Hub**.

## Was macht den Tapo S200B interessant?

Smart-Home-Geräte lassen sich bequem per App steuern. Für alltägliche Aktionen kann das Smartphone aber unnötig umständlich sein.

Genau hier setzt der Tapo S200B an.

Ein Druck auf die Taste kann beispielsweise eine zuvor festgelegte Smart-Home-Aktion starten.

Zum Beispiel:

`1× Tippen → Licht ein / aus`

oder:

`2× Tippen → andere Smart-Aktion`

Auch die Drehbewegung kann verwendet werden, beispielsweise zur Steuerung der Helligkeit kompatibler Beleuchtung.

Damit wird der S200B zu einem physischen Bedienelement für häufig verwendete Smart-Home-Funktionen.

## Einzeltippen, Doppeltippen und Drehen

Der Tapo S200B bietet drei grundlegende Bedienmöglichkeiten:

- Einzeltippen
- Doppeltippen
- Drehen

Je nach Einrichtung und verbundenen Geräten können damit unterschiedliche Aktionen ausgelöst werden.

Beispielsweise kann ein einfacher Tastendruck das Licht ein- oder ausschalten, während eine andere Eingabe eine weitere Smart-Home-Aktion startet.

Über die Drehsteuerung lässt sich bei kompatiblen Geräten beispielsweise die Helligkeit verändern.

## Bis zu vier Aktionen

Der S200B kann für bis zu **vier verschiedene Aktionen** konfiguriert werden.

Dadurch muss die Taste nicht auf eine einzige Funktion beschränkt bleiben.

Welche Aktionen tatsächlich zur Verfügung stehen, hängt von den verwendeten Tapo-Geräten und der jeweiligen Smart-Home-Konfiguration ab.

Das macht den Button besonders interessant, wenn mehrere kompatible Geräte bereits Teil des Tapo-Systems sind.

## Licht ohne Smartphone steuern

Einer der einfachsten Anwendungsfälle ist die Lichtsteuerung.

Statt:

`Smartphone → App öffnen → Gerät auswählen → Licht schalten`

kann eine konfigurierte Aktion direkt über den S200B ausgelöst werden.

Das ist besonders praktisch für Funktionen, die jeden Tag mehrfach verwendet werden.

Je nach kompatibler Beleuchtung und Einrichtung können beispielsweise Ein/Aus-Funktionen oder Einstellungen wie die Helligkeit gesteuert werden.

## Smart-Aktionen per Knopfdruck

Der S200B ist nicht ausschließlich für Lampen gedacht.

Er kann als Auslöser für kompatible Smart-Home-Aktionen innerhalb des Tapo-Systems verwendet werden.

Dadurch können mit einem Tastendruck auch Abläufe gestartet werden, an denen mehrere kompatible Geräte beteiligt sind.

Welche Möglichkeiten bestehen, hängt von den vorhandenen Geräten und den in der Tapo-App verfügbaren Automationen ab.

## Als intelligente Türklingeltaste

Eine weitere Einsatzmöglichkeit ist die Verwendung als einfache Smart-Home-Türklingeltaste.

Dafür wird der S200B beispielsweise in der Nähe der Eingangstür montiert und mit einem kompatiblen Tapo Hub gekoppelt.

Beim Drücken der Taste kann der Hub als akustischer Signalgeber verwendet werden.

Damit lässt sich innerhalb des Tapo-Systems eine einfache kabellose Klingellösung aufbauen.

## Zusätzliche Taste für wichtige Aktionen

Eine physische Smart-Home-Taste kann auch dort sinnvoll sein, wo eine bestimmte Aktion schnell erreichbar sein soll.

Der S200B lässt sich beispielsweise in einem Schlafzimmer oder einem anderen häufig genutzten Bereich platzieren.

So muss für eine vorbereitete Smart-Home-Aktion weder nach dem Smartphone gesucht noch zunächst eine App geöffnet werden.

Wichtig: Der S200B ersetzt keine professionelle Notruf- oder Sicherheitseinrichtung.

## Flexible Montage

Der Tapo S200B muss nicht an einem festen Platz installiert werden.

Er kann beispielsweise:

- auf einen Tisch gelegt werden
- auf einem Nachttisch verwendet werden
- mit dem mitgelieferten Klebematerial befestigt werden
- an einer geeigneten magnetischen Oberfläche angebracht werden

Dadurch lässt sich der Button dort platzieren, wo die jeweilige Smart-Home-Funktion am häufigsten benötigt wird.

## Batteriebetrieb mit CR2032

Der S200B verwendet eine austauschbare **CR2032-Knopfzelle**.

Die stromsparende Funkverbindung ist für batteriebetriebene Smart-Home-Geräte ausgelegt.

Dadurch benötigt der Button weder ein Stromkabel noch eine Steckdose und kann flexibel im Haus platziert werden.

Wie lange die Batterie tatsächlich hält, hängt unter anderem von Nutzung und Umgebungsbedingungen ab.

## Tapo Hub erforderlich

Ein wichtiger Punkt vor dem Kauf:

Der **Tapo S200B funktioniert nicht als eigenständiges WLAN-Gerät**.

Für die Nutzung wird ein kompatibler **Tapo Hub** benötigt.

Wer noch keinen passenden Hub besitzt, sollte dessen zusätzliche Anschaffung deshalb beim Gesamtpreis berücksichtigen.

Wer bereits einen Tapo H100, H200 oder einen anderen kompatiblen Tapo Hub verwendet, kann den S200B dagegen als weiteres Bedienelement in das bestehende System integrieren.

- ein herstellerübergreifender Smart-Home-Button gesucht wird
- nur eine einzelne selten genutzte Smart-Home-Funktion vorhanden ist

In diesen Fällen bringt eine zusätzliche physische Taste möglicherweise nur wenig Mehrwert.
